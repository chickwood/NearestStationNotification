# 附近车站通知 🚉

**附近车站通知**（Nearest Station Notification / 最寄り駅通知）会根据你的当前位置，实时找出距离最近的车站并显示在列表中；当最近车站发生变化时，应用会发送一条安静的通知。

无需设置范围，也不依赖地图：只要移动，应用就会持续更新最近车站。

## 功能特点

- **始终指向最近车站**：无论距离远近，列表首位始终是当前最近的车站。
- **切换时通知**：最近车站发生变化时自动提醒，通知显示车站名称与线路 ID。
- **安静、不打扰**：通知无声、无振动，不弹出额外交互。
- **可作为常驻工具**：开始定位后可退到后台继续工作。
- **车站数据可更新**：车站信息与活动信息可通过导入数据包手动更新。
- **多语言界面**：跟随系统语言，支持简体中文、日语和英语。

## 安装

安装包请从项目的 **Releases / 发布页** 获取。安装后首次启动会使用随应用附带的示例车站数据，建议按「更新车站与活动数据」导入完整数据。

### Android

1. 下载并安装最新版本的 APK；如系统提示，请允许安装来自该来源的应用。
2. 首次开始定位时，允许**位置信息**权限（仅在使用期间即可）。
3. 允许**通知**权限，以便接收最近车站变化提醒。
4. 应用会使用前台服务在后台持续定位，通知栏会出现一条常驻服务通知。

### iOS

1. 通过发布页提供的安装渠道安装应用。
2. 首次开始定位时，允许**位置信息**访问；应用会在后台使用定位。
3. 允许**通知**权限。

> 系统要求：Android 10 及以上、iOS 16 及以上。

## 快速上手

1. 打开应用，点击右上角的 **▶ 开始** 按钮。
2. 按提示允许定位与通知权限。
3. 等待首次定位完成，列表将显示附近车站，首位为最近车站。
4. 需要停止时，点击右上角的 **■ 停止** 按钮。

定位启动期间，按 Android 返回键不会退出应用，而是将应用移到后台继续定位；如需完全停止，请先点击停止按钮。

## 界面说明

| 位置 | 内容 |
|---|---|
| 顶部 **▶ / ■** | 开始或停止定位；启动过程中也可点击停止 |
| 顶部 **设置** | 调整检出车站数与定位更新间隔 |
| 顶部 **信息** | 查看车站数据版本、许可证，以及导入数据包 |
| 列表标题右侧图标 | 切换坐标显示：隐藏 → 经纬度 → 经纬度及速度、精度、方向、更新时间 |
| 列表 | 附近车站按距离排序；第 1 项以橙色高亮 |

列表中的颜色块表示车站所属的分组（普通 / 活动期间 / 扩展检索范围），不同分组使用不同底色区分。

## 设置

打开右上角的 **设置**：

- **检出车站数**
  - **标准**：通常显示 18 个车站；活动期间会增加 2 个，共 20 个。
  - **最大**：固定显示 20 个车站。
- **定位更新间隔**
  - **1 秒 / 3 秒 / 5 秒**。间隔越短越及时，也越耗电；步行或停留时建议 3～5 秒。

设置会立即生效并自动保存。

## 更新车站与活动数据

应用内的车站数据与活动数据不会自动更新，需要手动导入：

1. 确保已连接网络。
2. 点击右上角的 **信息** 按钮。
3. 点击「更新」提示框，打开数据下载网站。
4. 下载最新的数据包（ZIP 文件）。
5. 返回应用，在信息对话框中点击 **导入**，选择刚下载的 ZIP 文件。
6. 导入成功后，列表会在下一次定位时使用新数据；活动信息会立即生效。

说明：

- 数据包中可只包含车站数据、只包含活动数据，或两者都包含。
- 应用会自动校验数据包的完整性和格式；校验未通过的数据包不会写入任何文件。
- 如果导入失败，原有数据仍然有效，可重新下载后再试。
- 请只导入来自官方下载网站的数据包。

## 通知说明

- 只有在**最近车站发生变化**时才会更新业务通知，避免频繁打扰。
- 通知显示最近车站名称与线路 ID；默认无声、无振动。
- 通知不会自动消失，方便随时查看。
- Android 上另有一条 Geolocator 前台服务常驻通知，用于维持后台定位；可长按该通知选择隐藏。

## 权限与隐私

应用会请求以下权限：

- **位置信息**：用于计算与车站的距离，以及判断最近车站是否变化。
- **通知**：用于在最近车站变化时提醒。
- **前台服务 / 后台定位**：在应用退到后台后继续更新车站。

定位计算全部在本机完成；应用没有账户体系，也不会将你的位置上传到服务器。应用仅在打开数据下载网站时调用系统浏览器。

## 常见问题

**开始后一直显示「定位更新中...」**

请确认系统定位已开启、应用拥有位置权限，并在室外或信号较好的位置等待首次定位。

**列表显示「定位停止中...」并提示正在使用示例数据**

应用当前使用随包附带的示例数据。请按「更新车站与活动数据」导入完整车站数据，提示会自动消失。

**没有收到通知**

- 确认已允许通知权限。
- 业务通知只在最近车站变化时发送；停留在同一最近车站附近不会重复提醒。
- Android 上请避免系统对应用施加严格的后台限制，并保留前台服务通知。

**更新后车站没有变化**

导入成功后，新数据会在下一次定位更新时生效；活动信息的搜索名额会立即生效。若仍无变化，请确认数据包来自官方下载网站且导入成功。

**如何完全退出**

先点击右上角的停止按钮，再退出应用。定位进行中按 Android 返回键只会将应用移到后台。

## 多语言

界面语言跟随系统设置，支持：

- 简体中文
- 日语
- 英语

系统语言不在上述范围内时，界面使用英语。
